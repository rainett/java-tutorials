# What is a package
Package is a namespace that organizes a set of related classes and interfaces.
You can consider it as a folder on your computer. In one, you may have images, in another videos, 
in another MS Word documents and so on. Because software written in Java can contain hundreds or 
thousands of classes, it's important to keep everything organized by packages.
Java itself provides an enormous class library (set of packages) suitable for use in your own
apps.
